## 项目简介

&emsp;&emsp;本项目基于 RuoYi-Vue-Plus 框架快速搭建，是一个支持多租户的智能客服系统，用户可自定义知识库、上传文档并分段，对大模型生成的问题进行微调，最后与大模型进行对话。

- 技术栈：SpringBoot + MySQL + Redis + PostgreSQL + LangChain4j + SSE
- 前端项目地址：[Customer-Service-Agent-Vben](https://github.com/haipeng-lin/Customer-Service-Agent-Vben)
